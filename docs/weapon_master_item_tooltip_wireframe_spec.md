# ウエポンマスター 武器情報ツールチップ仕様(確定版)

対応図面: `weapon_master_item_tooltip_wireframe.svg`

## 1. 表示トリガー

バトル準備画面のバックパック内にある**武器/素材の画像にカーソルを当てる(ホバーする)**と、
その場に情報ポップアップ(ツールチップ)を表示する。

## 2. 表示内容

| 位置 | 内容 |
|---|---|
| 上段左 | 武器/素材の名前 |
| 上段右 | レアリティ(★アイコンの数で表現)+ 詳細アイコン(i) |
| ステータス欄 | ダメージ・スタミナ消費量・命中率・使用間隔・奥義ゲージ獲得量 を2列のボックスで表示 |
| 固有効果欄 | 「固有効果:」ラベル + 効果の説明文(複数行) |
| カテゴリ欄 | 「カテゴリ:」ラベル + カテゴリバッジを複数表示(例: 武器・槍) |
| 強調バッジ(下部) | 特定のキーワード効果(例: 「ブロック」)を強調表示するバッジ |

- カテゴリは図鑑画面のタグ一覧(武器/防具/ライセンス/秘宝/合成)と対応させる想定。
  加えて武器種別(槍・剣など)のような**サブカテゴリも複数バッジで併記**する
- ステータス項目(ダメージ/スタミナ消費量/命中率/使用間隔/奥義ゲージ獲得量)は、
  検証用ゲームデザイン仕様書のATK/SPD等の数値と対応させる形でマスタデータを拡張する必要がある
- 下部の強調バッジは、固有効果の中で特に重要なキーワード(例: 「ブロック」)を
  アイテムごとに0〜複数個表示する想定
- レイアウトは共有された参考画像と同じ配置を採用

## 3. 今後の検討事項

- 詳細アイコン(i)を押した場合の追加挙動(図鑑の該当ページへ遷移するかどうか)
- ホバーできない操作環境(タッチデバイスなど)での代替表示方法(タップで表示/消去、など)
