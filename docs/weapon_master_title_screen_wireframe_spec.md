# ウエポンマスター タイトル画面ワイヤーフレーム仕様(確定版)

対応図面: `weapon_master_title_screen_wireframe.svg`

## 1. 構成

中央にタイトルロゴ、その下にボタンを縦一列に配置するシンプルな構成。

| 要素 | 内容 |
|---|---|
| ロゴ | 「ウエポンマスター」のタイトルロゴ表示エリア |
| ボタン1 | ランクマッチ |
| ボタン2 | カジュアルマッチ |
| ボタン3 | 図鑑(押下で図鑑画面ワイヤーフレームへ遷移) |
| 丸型ボタン(右下) | あそびかた |

## 2. 設定について

- 当初「設定」ボタンとして配置していた枠は**「図鑑」に変更**し、タイトル画面からの図鑑への導線とした
- これに伴い、タイトル画面から設定への導線は一旦廃止
- 音声調整・画面サイズ調整など、設定として必要な項目が現時点では未確定のため、
  **設定画面は一旦実装対象外**とする
- **設定画面は実装しない方針で確定**(タイトル画面からの導線も設けない)

## 3. 「あそびかた」ボタンの仕様

- 押下すると**専用のワイヤーフレーム画面には遷移せず、ポップアップ表示**で説明を行う方針
- 説明内容は**画像による解説**を予定(テキストではなく画像ベース)
- そのため「あそびかた」については画面遷移のワイヤーフレームを別途作成しない

## 4. 未確定事項

- バージョン表記など、ロゴ下・画面下部の補助情報は仮配置のプレースホルダー
- 「あそびかた」ポップアップに使用する解説画像の内容・枚数は未確定
