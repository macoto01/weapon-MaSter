# ウエポンマスター 図鑑画面ワイヤーフレーム仕様(確定版)

対応図面: `weapon_master_encyclopedia_wireframe.svg`

## 1. 画面の位置づけ

バトル準備画面からは切り離し、**タイトル画面のリンクからアクセスする独立画面**として扱う。

## 2. ヘッダー

- 左: 「図鑑」タイトル
- 右: 「戻る」(押下で**タイトル画面へ遷移**する)

## 3. タグ一覧(左パネル)

以前の「アイテム一覧」から名称・役割を変更し、**個別アイテムではなくカテゴリ(タグ)を選択する一覧**とした。

| タグ | 内容 |
|---|---|
| 武器 | 攻撃用アイテム全般 |
| 防具 | 防御用アイテム全般 |
| ライセンス | 特殊資格・パッシブ系アイテム(想定) |
| 秘宝 | レア枠のユニークアイテム(想定) |
| 合成 | 合成レシピ関連情報(想定) |

選択中のタグはハイライト表示(図面では「武器」が選択状態)。

## 4. アイテム一覧(右パネル)

以前の「選択中(単一アイテム詳細)」から名称・役割を変更し、
**選択したタグに属するアイテムのリスト表示**に変更した。

各アイテム行に表示する情報:

- アイテム名
- **レアリティ(★表記)** ※今回追加
- ATK / SPD(または役割の簡易表記)
- **スキル詳細** ※今回追加(合成条件やパッシブ効果の説明)

## 5. 未使用アイテムの表示(?????)

- 「?????」による伏せ表示は**アイテム一覧(右パネル)にのみ実装**する
- 対象は**まだ使用したことがないアイテム**
- タグ一覧側(左パネル)では常にタグ名を表示し、伏せ表示は行わない

## 6. 今後の検討事項

- 防具・ライセンス・秘宝・合成タグそれぞれのアイテム一覧表示内容の詳細設計
- レアリティ区分の具体的な段階数・入手難易度との対応
- 「?????」状態から情報開示に切り替わるタイミング(遭遇時か、使用時か)の仕様確定
