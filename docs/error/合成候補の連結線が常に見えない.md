# 合成候補の連結線が常に見えない

**発生Step**: Step 4-2(合成候補の視覚化)
**症状**: レシピに合致する隣接ペア(例: ソード+砥石)を配置すると、各アイテムの縁はオレンジ色に光るが、
仕様書にある「線で結ぶ」演出がまったく見えない。
**原因**: `public/js/grid_renderer.js`の`draw()`で、合成候補を結ぶ接続線の描画処理が
アイテム本体(画像またはカラー矩形)の描画処理より**先**に実行されていた。合成候補は
「隣接(接触)している」場合のみ検出される仕様のため、接続線の両端は必ず双方のアイテムの
内側(中心点)に来る。そのため描画順が先だと、線は直後に描かれるアイテム本体の塗りつぶしで
常に完全に覆い隠されてしまい、原理的に一度も視認できない状態だった。
**解決策**: 接続線を描画するブロックを`items.forEach(...)`によるアイテム本体描画の**後**に
移動し、線がアイテムの上に重なって見えるようにした。
**関連ファイル**: `public/js/grid_renderer.js`
