# ブラウザでアクセスするとスピナーが止まらず応答しない

**発生Step**: 該当なし(開発環境のサーバー起動設定に関する問題)
**症状**: `php artisan serve`でサーバーを起動し、ブラウザ(ポートフォワーディング経由)でアクセスすると、スピナーが回り続けたまま応答が返ってこない。コンテナ内から`curl http://127.0.0.1:8000/`を実行すると正常に200が返り、サーバープロセス自体も落ちていなかった。
**原因**: サーバーが`127.0.0.1`(ループバックアドレス)のみでリッスンしていたため。ループバックはコンテナ自身からの接続しか受け付けず、ブラウザはポートフォワーディング経由で外部インターフェース(`0.0.0.0`相当)から接続しに来るため、応答するプロセスが存在せず接続がタイムアウトするまでハングしていた。
**解決策**: `php artisan serve`の起動ホストを`127.0.0.1`から`0.0.0.0`に変更し、外部インターフェースからの接続も受け付けるようにした。起動直後の疎通確認(readiness check)は引き続きコンテナ内部向けの`127.0.0.1`を使用。
