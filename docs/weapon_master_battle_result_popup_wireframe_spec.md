# ウエポンマスター バトル結果ポップアップ仕様(確定版)

対応図面: `weapon_master_battle_result_popup_wireframe.svg`

## 1. 画面の位置づけ

バトル結果専用のページ(画面遷移)は用意しない。
**バトル画面の上に半透明オーバーレイを重ねたポップアップ**として結果を表示する方針。

## 2. 対戦ルール

- 1マッチは**全15戦**を上限とする
- **ライフ制**: ライフは5からスタートし、敗北するたびに1減る
- **勝利条件**: **10勝**でクリア
- 終了条件は「10勝達成」「ライフ0(5敗)」「15戦消化」のいずれか

## 3. ポップアップの表示内容

「勝利のみシンプルに」という方針のもと、以下の要素のみで構成する。

| 要素 | 内容 |
|---|---|
| 勝敗タイトル | 「勝利」または「敗北」を大きく表示 |
| 勝利マーク | 10個の空欄マークを用意し、勝利するたびに塗りつぶしマークが重なっていく(数字表記なし) |
| ライフマーク | 5個のマークからスタートし、敗北するたびに1つ消えていく(数字表記なし) |
| 次へボタン | 押下でバトル準備画面へ戻る(通常時のみ。詳細は4節参照) |

## 3.1 終了条件による表示・遷移先の分岐(確定)

マッチの終了条件によって、ポップアップの表示内容と「次へ」ボタンの遷移先を変える。

| 終了条件 | 表示 | ボタン遷移先 |
|---|---|---|
| 通常の1戦(継続中) | 「勝利」または「敗北」のみ | バトル準備画面(次のラウンドへ) |
| 10勝達成(クリア) | 表示を変更(例:「クリア」) | **タイトル画面**へ戻る |
| ライフ0(5敗・ゲームオーバー) | 表示を変更(例:「ゲームオーバー」) | **タイトル画面**へ戻る |

- 勝利マーク・ライフマークともに**テキストラベルや数字は表示しない**。マークの見た目のみで進捗を伝える。
- 獲得マニーや新規武器入手などの情報は、今回は含めない(勝敗のみのシンプル構成)
