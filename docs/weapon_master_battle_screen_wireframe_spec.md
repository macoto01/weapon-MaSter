# ウエポンマスター バトル画面ワイヤーフレーム仕様(確定版)

対応図面: `weapon_master_battle_screen_wireframe.svg`

## 1. 全体構成

画面は縦に「プレイヤー情報」「VSパネル」「敵情報」「SKIPボタン」の順で構成される。

## 2. プレイヤー情報エリア

- **バックパック(左)**: バトル準備画面ワイヤーフレームで確定した仕様をそのまま流用。
  8×7マスを予約し、使用可能なのは右下に1マスずつシフトした4×3マスのみ。
  サイズはバトル準備画面のものよりコンパクトに縮小して配置。
- **プレイヤーイラスト(右)**: 等身大で配置(縮小・下配置は行わない)
- **TIME枠 / 一時停止ボタン**: 右上に配置。両方とも同一サイズ(80×24)に統一し、
  TIME枠の直下に一時停止ボタンを配置する。

## 3. VSパネル

- 左にプレイヤー(Ram)、右に敵(みざ)のステータスを配置
- 各ブロックの内容: アイコン + 名前、HPバー、STバー
- **盾アイコン**: HP/STバーの右横に縦長のアイコンとして配置。
  耐久値は今後アイコン上部に数値表示を実装予定(現時点のワイヤーフレームでは
  数値・バッジ枠は含めず、アイコン本体のみを表示)
- **VSアイコン**: 中央に配置し、両パネルの枠に接触しないよう間隔と半径を調整
- 各パネルの下に状態異常/バフ表示欄を確保(内容は今後検討)

## 4. 敵情報エリア

- **敵イラスト(左)**: 等身大で配置
- **バックパック(右)**: プレイヤー側と同様の8×7予約/4×3使用可能仕様を、
  コンテナ右端に寄せて配置(プレイヤー側と左右対称の構成)

## 5. SKIPボタン

- 敵情報エリア(バックパック枠)の右下に配置
- 画面下部に独立した再生バー・時間表示・音量ボタンなどは実装しない
  (検討段階で参考にした動画プレイヤー風UIの要素は不要と判断し削除)

## 6. 今後の検討事項

- 盾の耐久値の具体的な表示形式(アイコン上部への数値表示の実装方法)
- 状態異常/バフ表示欄の具体的な内容・アイコン種別
- TIME枠・一時停止ボタンの機能仕様(何の時間を計測しているか、一時停止で何が止まるか)
- バックパックの「コンパクトサイズ」の正式な寸法値の確定
