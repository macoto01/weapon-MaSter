# ウエポンマスター 画面遷移フロー図(確定版)

対応図面: `weapon_master_screen_flow_diagram.svg`

## 1. 遷移の全体像

```
あそびかた(ポップアップ) ← タイトル画面 → 図鑑画面
                              ↓ ランクマッチ / カジュアルマッチ
                        バトル準備画面 ←─────────────┐
                              ↓ バトル開始              │いいえ
                        合成確認ポップアップ(候補がある場合のみ)
                              │ はい                     ↑(上のいいえと同じ矢印)
                              ↓
                          バトル画面
                              ↓ 終了後
                        バトル結果ポップアップ
                              ↺ バトル準備画面へ戻る
```

## 2. 各遷移の詳細

| 遷移元 | 遷移先 | トリガー | 備考 |
|---|---|---|---|
| タイトル画面 | (画面遷移なし) | 「あそびかた」ボタン | ポップアップで画像による解説を表示。専用画面は持たない |
| タイトル画面 | 図鑑画面 | 「図鑑」ボタン | タイトル画面のボタン名称を「設定」から変更して対応 |
| タイトル画面 | バトル準備画面 | 「ランクマッチ」または「カジュアルマッチ」ボタン | 対戦モードの選択後、共通のバトル準備画面へ遷移 |
| バトル準備画面 | 合成確認ポップアップ | 「バトル開始」ボタン(合成候補がある場合のみ) | 「合成する武器がありますが問題ないですか?」を確認 |
| 合成確認ポップアップ | バトル画面 | 「はい」 | 合成を確定してバトル開始 |
| 合成確認ポップアップ | バトル準備画面 | 「いいえ」 | ポップアップを閉じるのみ。配置はそのまま維持 |
| バトル準備画面 | バトル画面 | 「バトル開始」ボタン(合成候補が無い場合) | 合成確認ポップアップを経由せず直接遷移 |
| バトル画面 | バトル結果ポップアップ | 対戦終了後(または「SKIP」使用後) | 勝敗・勝利マーク・ライフマークを表示 |
| バトル結果ポップアップ | バトル準備画面 | 「次へ」ボタン(通常時) | 次ラウンドの準備のため、バトル準備画面へ戻るループ構造 |
| バトル結果ポップアップ | タイトル画面 | 「次へ」ボタン(10勝クリア、またはライフ0のゲームオーバー時) | 表示内容を変更した上でタイトル画面へ戻る |
| 図鑑画面 | タイトル画面 | 「戻る」ボタン | 図鑑を見終えたらタイトル画面に戻る(他画面への遷移は無し) |

## 3. 決定事項まとめ

- 図鑑画面からの遷移先は**タイトル画面のみ**
- バトル結果ポップアップは、10勝クリア・ライフ0のいずれかの場合に表示と遷移先(タイトル画面)を変更する
- **設定画面は実装しない**(タイトル画面からの導線も無し)
