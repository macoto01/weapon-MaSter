# ウエポンマスター バトル準備画面ワイヤーフレーム仕様(確定版)

対応図面: `weapon_master_battle_prep_screen_wireframe.svg`

## 1. ヘッダー(y: 10〜90)

| 領域 | 内容 |
|---|---|
| 左(プレイヤー情報) | アイコン + プレイヤー名 + レベル |
| 中央(ステータス) | HP・ST・ST消費量を数値のみで表示(バー表示・「/」表示なし)。各行の間に区切り線を挿入 |
| 右上(ラウンド) | 独立した枠でラウンド数を表示 |
| 右端 | 設定/メニュー |

## 2. バックパック(y: 100〜450)

- 全体は**8×7マスを予約**した拡張予定エリア(破線表示)
- 初期状態で使用可能なのは**4×3マスのみ**(実線・塗りつぶし表示)
- 使用可能エリアは左上起点ではなく、**右下方向に1マスずつシフト**した位置に配置
- 戦闘終了ごとに+4マスずつ解放され、解放位置はユーザーが選択する(最大7×8相当まで拡張)

## 3. ショップ(y: 460〜600、全高は当初比1.4倍)

- 最大6品を**横一列**に表示
- 各アイテムの**下に価格(マニー)を表示**
- 「更新(マニー消費)」ボタンは、**ショップ1番目のアイテムスロットの真下**に配置し、枠の境界を無視して少しはみ出す形で表示

## 4. 一時置き場・マニー・バトル開始(y: 606〜820)

| 要素 | 幅比率 | 内容 |
|---|---|---|
| 一時置き場 | 全体の約80% | バックパックに入りきらない武器を管理。内部に固定枠は持たず、自由配置エリアとして扱う |
| マニー表示 | 一時置き場の右上にバッジ状に配置 | 更新ボタンと同様、枠の境界を無視してはみ出す形で表示 |
| バトル開始枠 | 全体の約20% | 上部30%に「バトル開始」ボタン、下部70%に商売人(女の子)のイラスト領域を配置(ボタン3:イラスト7の比率) |

## 5. この画面から削除された要素

- **図鑑**: バトル準備画面には表示しない。タイトル画面からのリンク経由でアクセスする方針
- **合成ボタン/合成パネル**: 本ワイヤーフレームからは削除。以下の新方式に置き換えた

## 5.1 合成システム(新方式・確定)

- 合成はプレイヤーが手動で選択する形式ではなく、**バックパック内で接触しているマス同士**を対象に、
  **対戦後**に自動で合成候補として判定される
- 合成候補になった武器は、**バックパック上のイラストの縁(ふち)が同じ色で光り、
  かつ対象同士を線で結ぶ**ことで表示する(縁の色+連結線の二重表現)
- この演出は**新しい画面を用意せず、バトル準備画面のバックパック表示上の状態変化**として実装する
  (バトル結果ポップアップ→バトル準備画面に戻った際、接触状態にあった武器が
  光った状態・線で結ばれた状態で表示される)
- **合成の確定操作**: 合成候補が存在する状態で「バトル開始」ボタンを押すと、
  **「合成する武器がありますが問題ないですか?」という確認ポップアップ**を表示し、
  プレイヤーの確認を取ってから合成を確定してバトルを開始する

## 6. マニー経済(画面設計に伴う仕様メモ)

- マニーは戦闘勝利(固定10マニー)、または武器売却(購入額の半額・端数切り捨て)によって増加する
- ショップの品揃え更新(固定1マニー)、武器購入(価格帯1〜8マニー、調整予定)でマニーを消費する

- **確認ポップアップで「いいえ」を選んだ場合**: ポップアップを閉じるのみで、バトルは開始しない
  (バックパックの配置状態はそのまま維持される)
- その後、再度「バトル開始」ボタンを押した際、合成候補がまだ存在すれば再度同じ確認ポップアップを表示する

## 7. ST・ST消費量について
ST：
のことを指し、武器が攻撃する際に必要な数減らす。(スタミナが減らせないと攻撃できない)
ST消費量：バックパックに設定されているすべての武器からスタミナ消費量の計算を行い、どの範囲に収まっているかで文字表記を行う。
・計算方法：武器に設定されているスタミナ消費/武器に設定されているクールダウン攻撃間隔秒数＝で出す
・表記判断：すべての武器のスタミナ消費量を足した数値が以下のような範囲の場合に左に設定したコメントを画面に出す。
　非常に少ない：0.00 ~ 0.50秒未満
　少ない　　　：0.50 ~ 0.90秒未満
　ほどほど　　：0.90 ~ 1.20秒未満
　多い　　　　：1.20 ~ 1.50秒未満
　非常に多い　：1.50秒以上
